# ADUC-Extended v1.2.9

## Что нового

- **Генератор паролей.** Кнопка **«Пароль…»** на панели инструментов
  открывает генератор; он же доступен по кнопке «Создать…» рядом с полем
  пароля в окнах **«Сбросить пароль»** и **«Создать пользователя»** —
  «Использовать» подставляет пароль в поля и копирует его в буфер обмена.
  - По умолчанию: строчные + заглавные буквы + цифры, 12 символов.
  - Настройки: длина ползунком **8–20**, спецсимволы (`!@#$%^&*-_=+?`)
    вкл/выкл и **«Исключить похожие символы»** (O/0, I/l/1, S/5, Z/2, B/8).
  - Каждый включённый набор гарантированно встречается хотя бы раз;
    символы берутся из криптографического генератора ОС. Настройки
    запоминаются на сессию.
- **Адаптивная панель инструментов.** Группы «поиск», «действия» и
  «домен» переносятся на две-три строки, когда окно узкое, — кнопки
  больше не обрезаются; поле поиска растягивается вместе с окном.

## Изменения, перенесённые из неопубликованной 1.2.8

- **Все почтовые адреса пользователя (Exchange).** В панели свойств
  появилась строка **«Почтовые адреса (Exchange)»** со всеми адресами,
  которые Exchange хранит для пользователя: основной SMTP-адрес (помечен
  *основной*), дополнительные smtp-псевдонимы и адреса других типов
  (SIP, X500 …) — тот же список, что на странице «адрес электронной
  почты» в центре администрирования Exchange. Данные берутся прямо из
  каталога (`proxyAddresses`), доступ к серверу Exchange не нужен; для
  пользователей других доменов из поиска по всем доменам тоже работает.
  - **Exchange нет?** Приложение проверяет, есть ли в лесу организация
    Exchange. Если нет — строка просто не показывается (к Exchange
    ничего не запрашивается); если Exchange есть, но ящика нет, в строке
    написано *«почтового ящика нет: у пользователя нет адресов Exchange»*.

### Из 1.2.7

- **Имя / Фамилия в «Изменить свойства».** В окне свойств пользователя
  добавлены поля **Имя** (`givenName`) и **Фамилия** (`sn`) над
  «Отображаемым именем», как в диалоге ADUC «Новый объект»; очищенное
  поле удаляет атрибут. Полное имя (CN) не меняется — переименование
  объекта по-прежнему выполняется через перемещение.
- **Поиск по всем сохранённым доменам.** Новый флажок **«Все
  сохранённые домены»** рядом с полем поиска (режим «Пользователи»)
  выполняет текстовый поиск — по имени / фамилии, логину
  (sAMAccountName / UPN) или e-mail — в каждом домене из списка
  сохранённых, с учётными данными текущей сессии.
  - Результаты из всех доменов сводятся в общий список; столбец
    **«Домен»** показывает, где найден объект. Статусная строка сообщает
    область поиска и перечисляет недоступные домены.
  - Объекты из других доменов показываются только для чтения: свойства
    отображаются, история и (во внутренней сборке) доступы работают, а
    действие (изменить, сбросить пароль, группы, переместить, …)
    предлагает **переключиться на этот домен** — после переключения
    поиск повторяется и объект выбирается автоматически. Массовые
    действия применяются только к подключённому домену.
  - Без текста поиска, а также в режимах «Компьютеры» / «Группы» список
    работает как раньше (только подключённый домен).
- **Смена домена (в том числе в другой лес).** Если при использовании
  текущей учётной записи целевой домен её отвергает
  (`invalidCredentials`), приложение повторяет подключение с тем же
  паролем и полностью записанным логином: сначала с указанием
  **домашнего** домена (`ДОМАШНИЙ\user`, `user@домашний.домен` — короткий
  логин, принятый домашним контроллером, целевой контроллер ищет в
  *своём* домене, а именно полная форма нужна для работы через доверие),
  затем — переписанным под **целевой** домен (`ЦЕЛЕВОЙ\user`,
  `user@целевой.домен`) для одноимённой учётной записи в другом лесу без
  доверия. NetBIOS-имя домашнего домена читается из каталога, а не
  угадывается по DNS. Если ни один вариант не принят, в сообщении об
  ошибке перечислены опробованные варианты и указано, что проверить
  (направление доверия, выборочная проверка подлинности) либо предложено
  выбрать «Другая учётная запись».
- **Диагностика подключения.** При неудачном входе или смене домена
  показывается ответ самого контроллера домена — включая код AD `data`
  (`52e` неверное имя/пароль, `533` учётная запись отключена, `775`
  заблокирована, `8232` требуется подписывание LDAP, …) с пояснением —
  для каждого опробованного варианта логина. Те же строки дописываются в
  `~/aduc_ext_switch.log` (macOS) / `%APPDATA%\ADUC-Ext\switch.log`
  (Windows); пароли не записываются.
- **Таблица по контроллерам стала надёжнее.** Список контроллеров домена
  определяется из трёх источников по очереди (биты учётной записи
  DC/RODC, OU=Domain Controllers, контейнер Sites леса); неудачный запрос
  больше не кэшируется на сессию, а если список так и не получен, панель
  свойств сообщает об этом с текстом ошибки сервера вместо молчаливого
  показа одного контроллера.
- **Таблица по контроллерам для объектов других доменов.** Для
  пользователя, найденного поиском по всем доменам, опрашиваются
  контроллеры *его* домена (текущей учётной записью, через доверие), и
  данные о входах / неверных паролях показываются по каждому контроллеру
  без предварительного переключения домена.
- **Быстрая смена домена.** В окне «Смена домена» при выбранной по
  умолчанию «Текущей учётной записи» фокус сразу на кнопке
  **Подключиться** — Enter переключает домен немедленно; Escape отменяет.

## Загрузки

Каждое приложение содержит **английский и русский** языки; переключение —
внутри приложения.

| Платформа | Исходники | Бинарники |
|---|---|---|
| Windows | `ADUC-Ext-1.2.9-windows.zip` | `ADUC-Ext-1.2.9-win-exe.zip` |
| macOS   | `ADUC-Ext-1.2.9-macos.zip`   | `ADUC-Ext-1.2.9-mac-app.zip` |

## Требования
- Windows: PowerShell 5.1 + модуль ActiveDirectory (RSAT); при отсутствии
  приложение предложит установить RSAT.
- macOS: Python 3.8+ с Tkinter; `ldap3` ставится автоматически.
