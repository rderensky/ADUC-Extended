# ADUC-Extended

Графическое приложение для повседневного администрирования Active Directory —
Windows (PowerShell + WPF) и macOS (Python + Tkinter).

ADUC-Extended — лёгкая альтернатива оснастке «Active Directory — пользователи и
компьютеры» для задач, которые служба поддержки и системные администраторы
выполняют каждый день. Одно и то же приложение существует для Windows и macOS,
двуязычно (**English / Русский**, переключение на лету) и работает от имени
учётной записи, под которой вы вошли, — на стороне сервера ничего не
устанавливается и не хранится.

## Что умеет

**Пользователи.** Поиск по имени, логину или e-mail; панель свойств с состоянием
учётной записи и пароля; создание со всеми привычными атрибутами; включение,
отключение и разблокировка; сброс пароля со встроенным генератором; флаг «срок
пароля не ограничен» с необязательной датой автоматического снятия;
редактирование атрибутов; перенос между подразделениями.

**Компьютеры и группы.** То же окно переключается на объекты-компьютеры и на
группы: поиск, свойства, создание, переименование, перенос, включение и
отключение, удаление. Членство в группах управляется с обеих сторон — группы
пользователя и участники группы (включая вложенные группы), с подборщиком,
который собирает участников из нескольких OU или результатов поиска в один список.

**Массовые операции.** Множественный выбор с групповыми действиями, дерево OU
для навигации и выбора цели, обработка совпадения имён при переносе и локальный
журнал изменений, в который попадает каждое действие, выполненное через
приложение, с указанием, кто его сделал.

**Несколько доменов.** Список сохранённых доменов с быстрым переключением (под
текущей или другой учётной записью) и поиск сразу по всем сохранённым доменам с
действиями над объектами из других доменов.

**Атрибуты Exchange.** Все почтовые адреса пользователя читаются напрямую из
каталога — доступ к серверу Exchange не нужен.

**Интерфейс.** Клавиатурные сочетания и контекстное меню в каждом поле, панель
инструментов, перестраивающаяся в узком окне, даты в формате выбранного языка и
надёжная работа буфера обмена на macOS в обеих раскладках.

Подробности по каждой функции и изменения в каждой версии — в
[примечаниях к выпускам](RELEASE_NOTES_ru.md).

## Быстрый старт

### Windows

```powershell
cd windows
powershell.exe -ExecutionPolicy Bypass -STA -File .\ADUC-Ext.ps1
```

Нужны Windows PowerShell 5.1 и модуль **ActiveDirectory** (RSAT). Если модуль
отсутствует, приложение предложит установить RSAT автоматически (нужны права
администратора). Сборка автономного `.exe` — `build_exe.ps1`.

### macOS

```bash
cd macos
python3 aduc_ext.py
```

Нужен Python 3.8+ с Tkinter; пакет `ldap3` ставится автоматически при первом
запуске. Рекомендуется LDAPS (порт 636): смена пароля и создание учётной записи
с паролем требуют защищённого соединения. Сборка `.app` — `build_app.sh`.

## Настройка

В начале каждого файла можно задать:

- **Подразделение (OU) для выбора групп** — по умолчанию не задано (показываются все
  группы домена):
  - Windows: `$Global:AccessGroupsOUName = "Имя OU"`
  - macOS: `ACCESS_GROUPS_OU_NAME = "Имя OU"`
- **Группы, добавляемые автоматически при создании** — по умолчанию пусто:
  - Windows: `$Global:DefaultCreateGroups = @('group1','group2')`
  - macOS: `DEFAULT_CREATE_GROUPS = ['group1', 'group2']`
- **Атрибут для даты автоснятия флага «срок пароля не ограничен»** —
  по умолчанию `adminDescription`:
  - Windows: `$Global:PwdNeverExpiresUntilAttr = 'adminDescription'`
  - macOS: `PWD_NEVER_EXPIRES_UNTIL_ATTR = "adminDescription"`

## Хранение настроек

Список доменов, язык интерфейса и журнал изменений хранятся локально; пароли не
сохраняются.

| Windows | macOS |
|---|---|
| `%APPDATA%\ADUC-Ext\domains.json` | `~/.aduc_ext_domains.json` |
| `%APPDATA%\ADUC-Ext\history.jsonl` (история изменений) | `~/.aduc_ext_history.jsonl` (история изменений) |

## Безопасность

- Пароль хранится только в памяти процесса на время сессии.
- Используйте учётную запись с минимально необходимыми правами.
- Часть операций требует соответствующих прав в каталоге; при их отсутствии
  операция завершится сообщением об отказе в доступе.
