# ADUC-Extended v1.0.2

## Что нового

- **Компьютеры** — переключатель «Пользователи / Компьютеры»: поиск, свойства,
  переименование, перенос между OU, изменение описания, включение/отключение,
  удаление.
- **Множественный выбор** в списке с групповыми действиями: включить,
  отключить, переместить в OU, а также групповое добавление выбранных
  пользователей в группы доступа.
- Управление флагом **«срок действия пароля не ограничен»**: кнопка действия,
  отмечаемый пункт контекстного меню и чекбокс в окне изменения. Как в
  оснастке ADUC, установка флага снимает требование смены пароля при
  следующем входе — прежний пароль остаётся действительным.
- **Двойной клик** по строке списка открывает окно редактирования
  (и для пользователей, и для компьютеров).
- macOS: автоматическое переподключение после простоя LDAP-соединения
  (исчезла ошибка «Broken pipe» после долгого бездействия).
- Windows: исправлены падение при подключении (привязка контекстного меню)
  и вёрстка верхней панели, где переключатель режимов обрезался.

## Загрузки

Каждый архив содержит **английскую и русскую** версии и README на двух языках.

|---|---|---|
| Windows | `ADUC-Ext-1.0.2-windows.zip` | `ADUC-Ext-1.0.2-win-exe.zip` |
| macOS   | `ADUC-Ext-1.0.2-macos.zip`   | `ADUC-Ext-1.0.2-mac-app-en.zip`, `ADUC-Ext-1.0.2-mac-app-ru.zip` |

## Требования
- Windows: PowerShell 5.1 + модуль ActiveDirectory (RSAT); при его отсутствии
  приложение предложит установить RSAT.
- macOS: Python 3.8+ с Tkinter; пакет `ldap3` устанавливается автоматически.
