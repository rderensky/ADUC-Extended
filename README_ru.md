# ADUC-Extended

Графическое приложение для управления учётными записями Active Directory —
Windows (PowerShell + WPF) и macOS (Python + Tkinter).

Единое двуязычное приложение: язык интерфейса (**English / Русский**)
переключается на лету — в окне входа и в главном окне. При запуске приложение
запрашивает учётные данные и выполняет все операции от имени указанной учётной записи.

## Возможности

- Поиск и просмотр свойств пользователей (в т.ч. сведения о пароле: дата
  изменения, требуемая смена, число неверных попыток входа).
- Компьютеры (переключатель «Пользователи / Компьютеры»): поиск, свойства,
  переименование, перенос между OU, изменение описания, включение/отключение,
  удаление.
- Навигация по дереву подразделений (OU).
- Создание учётных записей: имя, логин, UPN, e-mail, описание, пароль, выбор
  OU по дереву, срок действия, выбор групп; проверка на уже существующий логин.
- Включение, отключение, разблокировка учётных записей.
- Сброс пароля.
- Управление членством в группах, включая групповое добавление выбранных
  пользователей в группы.
- Работа с группами (переключатель «Пользователи / Компьютеры / Группы»):
  создание, изменение, переименование, перенос, удаление групп (в т.ч.
  массовое); список участников по двойному клику, добавление участников
  через дерево AD или поиск (отключённые учётные записи исключаются).
- Перемещение учётных записей между подразделениями.
- Множественный выбор с групповыми действиями: включить, отключить,
  переместить в OU.
- Управление флагом «срок действия пароля не ограничен» (как в ADUC, при
  установке снимается требование смены пароля при следующем входе).
- Изменение атрибутов; двойной клик по строке открывает окно редактирования.
- Список доменов с переключением; смена домена под учётными данными активной сессии.
- Переключение языка интерфейса (English / Русский) на лету; формат дат зависит
  от языка: `YYYY-MMM-DD` (EN) или `ДД МММ ГГГГ` (RU).
- Горячие клавиши в полях ввода: удаление строки (Cmd+Backspace на macOS,
  Shift+Backspace на Windows) и слова (Ctrl+Backspace); Esc закрывает
  активный диалог и никогда — главное окно.
- Вложенные группы: в окне редактирования группы — управление группами,
  в которые входит сама группа (Член групп), как в оснастке ADUC.
- Подбор участников с «корзиной»: двойной клик собирает пользователей из
  любого OU или поиска в один список — несколько участников из разных OU
  добавляются за один раз.
- Надёжный буфер обмена на macOS (Tk 9): Cmd+V/C/X/Z/A работают во всех
  полях, в английской и русской раскладках; контекстное меню по правому
  клику и отмена ввода (Cmd+Z).

## Быстрый старт

### Windows

```powershell
cd windows
powershell.exe -ExecutionPolicy Bypass -STA -File .\ADUC-Ext.ps1
```

Нужны Windows PowerShell 5.1 и модуль **ActiveDirectory** (RSAT). При его отсутствии
приложение предложит установить RSAT автоматически (нужны права администратора).
Сборка `.exe` — скриптом `build_exe.ps1`.

### macOS

```bash
cd macos
python3 aduc_ext.py
```

Нужен Python 3.8+ с Tkinter; пакет `ldap3` ставится автоматически при первом
запуске. Рекомендуется LDAPS (порт 636): смена пароля и создание учётной записи
с паролем требуют защищённого соединения. Сборка `.app` — `build_app.sh`.

## Настройка

В начале каждого файла можно задать:

- **Подразделение (OU) для выбора групп** — по умолчанию не задано (показываются все
  группы домена):
  - Windows: `$Global:AccessGroupsOUName = "Имя OU"`
  - macOS: `ACCESS_GROUPS_OU_NAME = "Имя OU"`
- **Группы, добавляемые автоматически при создании** — по умолчанию пусто:
  - Windows: `$Global:DefaultCreateGroups = @('group1','group2')`
  - macOS: `DEFAULT_CREATE_GROUPS = ['group1', 'group2']`

## Хранение настроек

Список доменов и язык интерфейса сохраняются локально (пароли не хранятся):

| Windows | macOS |
|---|---|
| `%APPDATA%\ADUC-Ext\domains.json` | `~/.aduc_ext_domains.json` |

## Безопасность

- Пароль хранится только в памяти процесса на время сессии.
- Используйте учётную запись с минимально необходимыми правами.
- Часть операций требует соответствующих прав в каталоге; при их отсутствии
  операция завершится сообщением об отказе в доступе.
