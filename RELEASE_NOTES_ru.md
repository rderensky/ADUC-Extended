# ADUC-Extended v1.2.0

## Что нового

- **Работа с группами** — третий режим в переключателе «Пользователи /
  Компьютеры / Группы»:
  - поиск групп с колонками Имя / Логин / Область / Категория / Описание;
  - создание групп (имя, логин, описание, область, категория, целевое OU);
  - изменение описания и e-mail; переименование; перенос между OU;
  - удаление групп, в том числе нескольких выбранных сразу;
  - **управление участниками**: список участников открывается двойным
    кликом; добавление — через дерево иерархии AD или через поиск
    (множественный выбор; отключённые учётные записи исключаются),
    удаление тоже множественное.
- **Быстрая ошибка при недоступном контроллере домена**: TCP-проверка за
  5 секунд вместо зависания (вход, смена домена и переподключение в сессии).

## Загрузки

Каждое приложение содержит **английский и русский** языки; переключение —
внутри приложения.

| Платформа | Исходники | Бинарники |
|---|---|---|
| Windows | `ADUC-Ext-1.2.0-windows.zip` | `ADUC-Ext-1.2.0-win-exe.zip` |
| macOS   | `ADUC-Ext-1.2.0-macos.zip`   | `ADUC-Ext-1.2.0-mac-app.zip` |

## Требования
- Windows: PowerShell 5.1 + модуль ActiveDirectory (RSAT); при отсутствии
  приложение предложит установить RSAT.
- macOS: Python 3.8+ с Tkinter; `ldap3` ставится автоматически.
